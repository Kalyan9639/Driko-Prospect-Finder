    FAST-MCP Connect with Claude Desktop, Cursor, Antigravity & ChatGPT
    Zero Gemini Tokens

    By running ICP Clarity Lab as a Model Context Protocol (MCP) Server, external AI reasoning engines (like Claude Desktop or ChatGPT) call our local Python scrapers and contact stitchers directly. Your local machine does all the heavy scraping, consuming zero Gemini API tokens!

    1. Claude Desktop Configuration:

    Add this snippet to your claude_desktop_config.json file: 

    {
  "mcpServers": {
    "icp-clarity-lab": {
      "command": "python",
      "args": ["-m", "app.mcp_server"],
      "cwd": "E:\\Jupyter Notebook\\ICP Lab"
    }
  }
}

    2. Available MCP Tools:

    • discover_prospects: Discovers real small/midsize companies with observable problem symptoms.
    • stitch_company_contacts: Resolves domain, parses JSON-LD, extracts public emails and LinkedIn pages.
    • list_unblocked_sources: Returns catalog of 50+ restriction-free public feeds.
    • generate_outreach: Synthesizes tailored Mom-Test openers, cold emails, and LinkedIn DM notes.
    • save_campaign_leads: Saves leads directly into the local GTM workbook store.
